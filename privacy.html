Privacy Policy

Last revised 27 September 2026.

Flat Peaks, published by Cyclamen Studio, does not collect personal data, run ads, or track you. There is no account to create and no server the game talks to during play. The one exception is an optional crash-reporting feature, off in one tap, described below.

What we collect by default

Nothing. Flat Peaks contains no advertising SDKs, no behavioural analytics, and no third-party trackers. It does not know your level progression, your session length, or anything else about how you play.

Crash and error reporting

Flat Peaks can optionally report crashes and errors to Sentry (Functional Software, Inc.), a third-party error-monitoring service, so bugs that would otherwise fail silently on your device can get fixed. This exists to report on the game, not on you.

The setting lives under Settings → Crash reports and defaults to on. Turn it off at any time and reporting stops immediately, including for anything already queued to send.

When enabled, a report can include the error type, message and stack trace; which part of the game it came from; the app version; and a random number identifying the current play session's simulation (not linked to you, your device, or any account — it exists so a report can be reproduced, not so it can be traced back to a person). A report never includes your save data, device identifiers, account information, or IP address (Sentry's IP capture is switched off for this app).

Whether this feature is active in the specific copy of Flat Peaks you installed depends on the build. The Data Safety section of this app's Google Play listing states the current answer for the version you have.

What the game stores

Your saved towns, settings and progress are written to local storage on your own device. They are never uploaded. They are not backed up to us, because there is no "us" to back them up to — we have no game servers.

Uninstalling Flat Peaks deletes this data permanently. You can also clear it from within the game at any time by starting a new game. Because the data never leaves your device, there is nothing for us to delete on request.

Permissions

Flat Peaks requests a single Android permission, INTERNET. Its only use is letting the optional crash reporting above reach Sentry when that setting is turned on; with it off, the app makes no network requests of its own.

It does not request access to your location, camera, microphone, contacts, photos, files, or any other sensitive permission.

Third-party components

Flat Peaks is built on a small number of open-source libraries, each used under its own licence, and the Sentry SDK described above when crash reporting is enabled. See the Open Source Licenses page for the full list.

Children

Flat Peaks is suitable for all ages and contains no user-to-user communication, no user-generated content, and no purchases. It does not collect data tied to any person — including through the crash reporting above, which is not linked to a device, account, or individual — so it does not knowingly collect personal information from children, and is consistent with COPPA and comparable children's privacy rules.

Changes to this policy

If crash reporting is ever enabled for a shipped build, or anything else changes about what can leave your device, this page is updated before that build is published, and the revision date above changes with it. The Data Safety declaration on this app's Google Play listing always reflects the version you installed.
